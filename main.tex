\chapter*{Note du transcripteur}
\addcontentsline{toc}{chapter}{Note du transcripteur}

Ce projet est une transcription du manuscrit intitulé
\textit{Histoire de la Congrégation des jeunes gens}, attribué à Benoît Coste.

Le document source comporte 182 vues manuscrites numérisées.
La transcription a été réalisée, pour l'essentiel, à l'aide d'un modèle d'intelligence artificielle. Les erreurs syntaxiques et grammaticales manifestes du manuscrit ont normalement été corrigées. Malgré les vérifications effectuées, des erreurs de transcription peuvent toutefois subsister.

Toute erreur relevée peut être signalée sur la page GitHub du projet :

\begin{center}
    \href{https://github.com/grostim/BenoitCoste-HistoireCongregation/issues}{\textbf{Signaler une erreur de transcription sur GitHub}}
    \vspace{0.5cm}
    \qrcode[height=3cm]{https://github.com/grostim/BenoitCoste-HistoireCongregation/issues}
    https://github.com/grostim/BenoitCoste-HistoireCongregation/issues
\end{center}

Les corrections seront intégrées lors d'une prochaine actualisation de la transcription. Le QR code ci-dessus renvoie vers cette même page afin de faciliter le signalement depuis la version imprimée.

Les versions actualisées de ce document, au format PDF et au format EPUB --- adapté aux liseuses et autres lecteurs numériques --- sont disponibles sur le dépôt GitHub du projet :

\begin{center}
    \href{https://github.com/grostim/BenoitCoste-HistoireCongregation/releases/latest}{\textbf{Consulter les versions actualisées sur GitHub: https://github.com/grostim/BenoitCoste-HistoireCongregation/releases/latest}}
 \end{center}
